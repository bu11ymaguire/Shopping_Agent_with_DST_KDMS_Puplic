# Development presentations

이 폴더는 프로젝트의 중간 점검, 사용 경험 정리, 최종 발표와 포스터 자료를 보존한다.
PPTX는 편집 가능한 원본이고, 같은 제목의 PDF는 최종 포스터의 열람용 사본이다.

파일은 작성 당시의 설명과 수치를 담은 기록이므로 현행 런타임 입력이나 재현 fixture로 사용하지
않는다. 구현·아키텍처 계약은 루트의 `flow.md`, 공식 수치는 동결 manifest와
`backend/docs/`의 결과 문서를 우선한다.

새 파일을 추가하거나 교체하기 전에는 자격 증명, 비공개 대화, 원본 리뷰, 개인 정보와 제3자
자료의 재배포 가능 여부를 확인한다.
